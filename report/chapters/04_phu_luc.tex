\chapter{Hướng dẫn cài đặt và chạy}
\label{app:caidat}

\section{Yêu cầu môi trường}

Python 3.10 trở lên, Node.js 18 trở lên. Không bắt buộc có GPU; hệ thống tự chọn
CUDA nếu máy có card NVIDIA, MPS trên chip Apple, còn lại chạy CPU.

\section{Khởi động máy chủ}

\begin{lstlisting}[language=bash, caption={Cài đặt và chạy backend}]
cd backend
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python run.py
\end{lstlisting}

Máy chủ lắng nghe tại \code{http://localhost:8000}, tài liệu API tại
\code{http://localhost:8000/docs}. Lần chạy đầu tiên, thư viện Ultralytics tự tải
tệp trọng số \code{yolov8n.pt} khoảng 6~MB.

\section{Khởi động giao diện}

\begin{lstlisting}[language=bash, caption={Cài đặt và chạy frontend}]
cd frontend
npm install
npm run dev
\end{lstlisting}

Mở trình duyệt tại \code{http://localhost:3000}. Vite chuyển tiếp mọi lời gọi
\code{/api} sang máy chủ ở cổng 8000, nên không cần cấu hình CORS khi phát triển.

\section{Thêm camera đầu tiên}

Vào trang \emph{Quản trị}, thẻ \emph{Nguồn camera}. Nhập tên, chọn loại nguồn rồi
điền đường dẫn: số \code{0} cho webcam tích hợp, chuỗi \code{rtsp://\dots} cho
camera IP, hoặc đường dẫn tuyệt đối tới tệp video. Bấm \emph{Kiểm tra kết nối}
trước khi lưu.

Sang trang \emph{AI Pipeline}, chọn camera vừa thêm, chọn bài toán \emph{Đếm đối
tượng ra/vào}, kéo vạch trên ảnh, rồi bấm \emph{Lưu và chạy ngay}.

\section{Mã DBML sinh sơ đồ quan hệ}
\label{app:dbml}

Dán đoạn mã dưới đây vào \url{https://dbdiagram.io} để sinh sơ đồ cho
Hình~\ref{fig:csdl}.

\begin{lstlisting}[caption={Mã DBML mô tả lược đồ cơ sở dữ liệu}]
Table cameras {
  id text [pk]
  name text
  location text
  source text
  kind text
  enabled int
  retention_days int
  created_at text
}

Table pipelines {
  id text [pk]
  name text
  camera_id text [ref: > cameras.id]
  task text
  classes text
  line text
  flip int
  conf real
  active int
  created_at text
}

Table events {
  id text [pk]
  ts text
  camera_id text [ref: > cameras.id]
  pipeline_id text [ref: > pipelines.id]
  type text
  direction text
  label text
  track_id int
  snapshot text
  message text
  status text
  note text
  handled_at text
}

Table counts {
  id int [pk, increment]
  ts text
  camera_id text [ref: > cameras.id]
  pipeline_id text [ref: > pipelines.id]
  in_total int
  out_total int
  occupancy int
}

Table segments {
  id text [pk]
  camera_id text [ref: > cameras.id]
  start_ts text
  end_ts text
  path text
  duration real
}
\end{lstlisting}

\section{Mã PlantUML sinh sơ đồ kiến trúc}
\label{app:plantuml}

Dán vào \url{https://www.plantuml.com/plantuml} để sinh ảnh cho
Hình~\ref{fig:kientruc}.

\begin{lstlisting}[caption={Mã PlantUML mô tả kiến trúc hệ thống}]
@startuml
skinparam componentStyle rectangle
skinparam defaultFontName Arial

package "Trinh duyet" {
  [Giao dien React] as UI
}

package "May chu Python (FastAPI)" {
  [REST API] as API
  [Camera Manager] as MGR
  [Camera Worker] as WK
  [Detector\nYOLOv8 + ByteTrack] as DET
  [Counter\nCentroidCrossing] as CNT
  [Segment Recorder] as REC
  [Search\nphan tich cau tieng Viet] as SRCH
}

database "SQLite" as DB
folder "Dia cung" as FS

UI --> API : REST + MJPEG
API --> MGR
MGR --> WK : mot luong moi camera
WK --> DET
DET --> CNT
WK --> REC
API --> SRCH
SRCH --> DB
CNT --> DB : su kien + so dem
REC --> FS : doan MP4
WK --> FS : anh chup JPEG
@enduml
\end{lstlisting}
